# Ethically Me, Anthony

A personal ethics portfolio by **Thomas Anthony Dator** for GED0061 - TE41.
It documents six everyday moral moments, my Personal Ethics Manifesto, and my moral growth throughout the semester.

**Live site:** https://tkmants.github.io/ethically-me/

## Built with
- HTML, CSS, and vanilla JavaScript (no frameworks)
- [DM Sans](https://fonts.google.com/specimen/DM+Sans) from Google Fonts

## Features
- Responsive layout for desktop, tablet, and mobile
- Light and dark mode
- Optional hover sound effects
- Pop-up reflections with space for photos
- Keyboard-friendly and screen-reader-friendly

## Files
```
index.html     page content
style.css      design and layout
script.js      menu, dark mode, sounds, reflection pop-ups
favicon.ico    browser tab icon
images/        portrait and Moral Moment photos
```

## Run locally
Open `index.html` in any modern browser.
